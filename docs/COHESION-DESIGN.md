# 0.9.1 材质协调

0.9.0 的前景树冠和船体是饱满色块，楼宇仍接近黑色细线稿，两者的体积、亮度和纹理密度不一致。本轮保留现有形状与场景内容，通过材质把整景接起来。

- 建筑、植物、船体与石铺装共享天空环境光。日光偏灰蓝，日落变暖，夜间压低漫反射；灯窗、导航灯与 Agent 信号仍独立发光。
- 楼宇增加较亮正面、冷暗侧面、窗洞和低对比楼层接缝。材质纹理和明暗系数随楼宇缓存，不在逐格绘制时重新计算噪声。
- 树冠保留不规则体积和分叉枝干，叶色收敛为灰绿与蓝绿，减少高亮 `%` 和 `*`，使纹理不抢过城市主体。
- 保留场景几何、船群规则、居民互动、世界随机数和采集逻辑。规则仍为 city-v9；回放使用当前材质。

`artifacts/cohesion/` 保存种子 20261102、366×115 字格的三城白天、黄昏、夜间前后对照及合成耗时。这些图是前端演示输入；原生截图另行标注。

复现视觉对照：运行开发服务后执行 `node tools/cohesion-check.mjs`。性能对照执行 `node tools/cohesion-performance.mjs`，要求事先在 `artifacts/cohesion-before/` 放入修改前的 0.9.0 源码和 index.html。原始参考 HTML 不参与修改。
