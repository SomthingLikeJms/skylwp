# 楼宇、树木与船只的材质统一（0.9.3）

本轮在 0.9.2 上调整绘制材质，不改变场景几何、居民行为、船群映射、采集频率或桌面层级逻辑。沿用 `city-v9` 记录规则；参考 HTML 保持原样。

楼宇、树木、船体采用公共灰蓝、石灰、木色与暖灯色，随同一天空受光。立面减少零散亮纹，窗洞阴影预先写入楼宇缓存；普通窗灯以暖色为主，Agent 扫描、告警和音乐灯光保留语义配色。

树冠按已有叶团计算受光与背光，用连续色面和稀疏字符表现体积；树干、枝条和船栏使用细线。船体增加一致的侧面暗部、边缘亮部与低对比货箱，保留九类船的轮廓、远近尺寸与不同城市渡轮。船向改变时，阴影仍保持世界中的光照方向。

固定种子 20261102，外滩、曼哈顿、维港各在 12:00、18:12、20:30 保存前后对照，共 18 张，分辨率 2560×1600、密度 7。对照使用相同模拟输入；真实采集截图单独命名为 `native-wallpaper.png`。结果在 `artifacts/harmony/`。

CPU 合成的交替采样：90 帧预热、每城每版 600 帧。214×60 网格新版本平均 1.15–1.83 ms，427×120 平均 4.53–4.78 ms；整体与旧版接近，4K 仍高于 4 ms 预算。本轮未重复整机 CPU、GPU、内存或长时间稳定性采样，不能将合成计时视为整机资源占用。
