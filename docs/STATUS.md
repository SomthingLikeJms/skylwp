# 当前交付：Windows 便携预览版 0.9.3

前端采用 TypeScript strict 与 Vite；原生壳采用 Tauri 2 / Rust。便携版可双击启动，使用已安装的 WebView2，自动接入本机信号并挂到桌面图标下面。

0.9.3 继续统一楼宇、树木与船只：共用灰蓝、石灰和木色材质与明暗比例；树冠按叶团受光，船体采用细边线和侧面阴影，普通窗灯偏暖。Agent 与音乐保留信号色。场景几何、居民互动和船群规则保持一致。

保留 0.9.2 的 Windows 11 桌面图标修复：壁纸模式约束自身窗口的前后顺序，沿用原有 5 秒检查修复独立层级变化；进入控制台时解除约束。无需重启 Explorer 或修改图标显示设置。

## 城市生活

- 四位普通居民自主买东西、找座位、看江景、候船与登船。咖啡窗口一次接待一人，长椅两座，渡轮六座；渡轮按世界时钟靠岸、开放登船、离港。
- 最近五个活跃会话与五个结束会话对应居民，加上普通居民最多 14 人。思考和空闲去店里，工具活动回工作台，等待确认去长椅，明确计划完成或会话结束去码头。报错时加快脚步并显示红色提示；系统 CPU 影响工作动作与工作台屏幕。
- 居民不会因短暂没有日志就完成任务；已登船后收到新任务会先完成航程再回来。场景切换和分辨率改变后重新找设施。导入旧记录会初始化居民，当前检查点保存行程、占座与航次。
- Codex 日志发现覆盖旧日期目录，跨日继续的会话仍可关联；已经跟踪的活跃日志保留优先级，文件未增长不重新读取。超时、关闭采集、中止或被新一轮替代会标记为停止跟踪，不冒充任务完成，也不放完成烟花。
- 两层缓存的远处城区、港口吊机、屋顶设备与植物、阳台、店招和立面明暗。维港在山体前补上住宅层次，店招只在完整可见时绘制。

## 原生功能

- 事件历史保留最近 15 分钟，每 30 秒创建检查点，并限制数量与字节容量；实时音频帧不进入前端历史。在线提示只在离开/回来时记录。
- Raw Input 事件驱动桌面点击；系统 CPU 读取缓存的自身进程句柄，每十秒更新一次进程树。浏览器订阅完整标签栏结构变化，以两秒局部校验补足漏报，并做低频整窗审计，Agent 跳过未增长的文件并清理跟踪表。
- WASAPI 事件驱动回环，静音降为每秒最多一帧；绘制调度按 12/30/6 fps 唤醒，暂停维护 1 Hz，隐藏时停止。
- 固定噪声系数、坐标相位、楼宇材质、山体和地面纹理缓存；缓存楼宇遮挡并跳过确定不可见的云层。生活内容使用有上限的字符图案与世界时钟，不增加后台轮询。

- 桌面空白单击烟花，原生监听保持鼠标穿透，排除桌面图标与拖动框选。
- 月亮保留圆形点阵，以 Emoji 的眉眼、嘴型、泪滴与冷暖表情表示系统城市实况天气；圆形轮廓抗锯齿，无外圈描边。
- 城市气候默认由本机负载驱动，实况不覆盖 CPU 阈值；可保存多云、雨、雷暴、内存雾、平滑和保持时间，也可选择跟随实况。
- 江面状态默认浓度 25%，两处低亮度文字显示 CPU、内存和最近 Agent 的实际动作，有计划显示进度，无计划显示工具次数；可改为 01 数值或普通倒影。

- CPU、内存、网络、空闲时长、前台最大化/全屏与电池状态。
- WASAPI 系统音频回环、FFT 三频段与七段频谱、起音与节拍估计。
- Windows 媒体会话的播放状态、曲名、艺人与封面主色。
- Codex / Claude Code 本地 JSONL 增量读取，不修改外部配置；浏览器辅助功能标签计数与可选类别扩展。
- 新版 Codex 桌面 item_completed 事件解析，识别思考、回复、实际命令结果、文件修改和 MCP 调用。活动卡片展示实际次数与更新时间，施工楼在没有计划时也可见。
- Open-Meteo 在线天气、Windows 系统城市、固定城市或跟随场景、十分钟刷新、离线缓存、温度、风、湿度及城市时区。系统城市采用本地 GeoNames 数据匹配，原始精确坐标不存储、不上传，天气只使用取整后的粗略坐标。
- 启动快照使用事件顺序号，同毫秒缓存事件保持先后顺序，快照到开始绘制之间的事件也保留。
- 统一的数字视觉：精细字符、电路纹理、扫描光带和信号流，保留物理像素字格密度；支持雨滴涟漪、雪、雷电、流星和雨后彩虹。
- 天气与 Agent 组件采用相同的等宽字体、硬边框和信号配色，可独立拖动、方向键微调、自动保存、重启恢复和重置布局。
- Windows 11 当前桌面层级和旧版 WorkerW 挂载，4K 高 DPI，跨虚拟桌面区域显示，Explorer 重启与布局变化后重挂。
- 托盘、隐私、暂停、全局快捷键、可选开机启动、逐项采集开关。
- 按天事件日志与十四天清理；JSONL 导出默认脱敏。

## 已验证

- TypeScript 严格类型检查和生产构建。
- 早期原貌版本曾通过原型字格缓冲逐字节对照；当前生活与远景扩展有意增加内容，不再宣称画面相同。参考 HTML 保持原样，固定种子截图用于美术对比。
- 不同绘制帧率下相同世界时间的帧哈希一致；检查点恢复、反复跳转、同时间戳事件和迟到事件可重放。
- 默认导出脱敏、输入事件校验、导入尺寸限制与中文双宽截断。
- Edge 浏览器中的场景、等待状态、隐私、回放、主题、密度和小窗口操作。

当前材质对照及耗时见 `artifacts/harmony/`，图标修复记录在 `artifacts/desktop-icons/`；其他历史结果在 `artifacts/cohesion/`、`artifacts/waterfront/`、`artifacts/city-life/` 与 `artifacts/comparison/`。
