ASCII City Wallpaper 0.5.0

The portable application uses open-source components including Rust, Tauri,
Wry, Tao, windows-rs, serde, serde_json, chrono, rand, tiny_http, sysinfo,
wasapi, rustfft, image, and their dependencies. Version pins and license
metadata are recorded in apps/shell/Cargo.lock and the Cargo registry metadata.
The browser frontend uses get-east-asian-width (MIT).

Offline city-name matching uses a reduced GeoNames cities15000 extract.
GeoNames: https://www.geonames.org/, Creative Commons Attribution 4.0.
Source: https://download.geonames.org/export/dump/cities15000.zip
License: https://creativecommons.org/licenses/by/4.0/
Only names, city coordinates and classification fields are retained.
These data are approximate place points, not administrative boundaries.
