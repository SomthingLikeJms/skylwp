# ASCII 城市动态壁纸便携版

官方下载：[GitHub Releases](https://github.com/SomthingLikeJms/skylwp/releases)。选择 Windows x64 便携 ZIP；浏览器演示包只提供模拟画面。

解压整个文件夹后，双击 `AsciiCity.exe` 或 `Start.cmd` 即可启动。程序使用电脑已有的 WebView2，无需安装 Node.js、Rust、Wallpaper Engine 或其他壁纸软件。请将 `WebView2Loader.dll` 与主程序放在同一目录。

升级前先退出旧程序，解压新版本覆盖应用文件，保留原目录的 `data` 文件夹。发布包附有 MIT 许可证、第三方许可声明；`SHA256SUMS.txt` 位于同一发布页面，可用 PowerShell `Get-FileHash 文件名 -Algorithm SHA256` 核对下载文件。

程序挂在桌面图标下面。双击托盘里的城市图标，或者右键选择“打开城市控制台”，可以进入交互模式。Esc 返回桌面。托盘菜单中的“退出壁纸”或 `Stop.cmd` 可停止程序。

0.9.2 修复壁纸偶尔遮住桌面图标的问题。壁纸窗口保持在图标下面，切回桌面时重新确认层级；系统独立调整层级时自动恢复，不修改“显示桌面图标”开关。

0.9.3 统一楼宇、树木与船体的材质：树冠按叶团分出明暗，船体使用细边线和侧面阴影，普通窗灯呈暖色；Agent 与音乐仍保留对应信号色。

## 管理小组件

打开城市控制台，在“画面”中点击“管理小组件”。拖动标题栏可以移动，方向键微调，Shift 加方向键移动十个像素。点击组件右上角的 × 将它从桌面移除，底部“城市天气”或“Agent 动态”按钮可以重新添加。移除组件不会关闭对应的数据采集。

默认透明度 82%，底部滑块可在 20%–100% 之间调整；只改变背景透明度，文字保持清晰。点击“完成”返回控制台。组件位置、显示状态和透明度自动保存，重启后保留。

## 场景生活

外滩的咖啡摊、曼哈顿的报刊亭、维港的茶档各不相同。普通居民会排队点单、端杯子找长椅、看江景、候船和登船；窗口一次接待一人，长椅有两座，渡轮可搭六人。雨天撑伞慢行，骑行暂停；水鸟在白天无风雨时出现。

真实 Agent 会带来对应颜色的居民：思考或空闲时去店里，等待确认时坐在长椅上，工具活动时回到工作台，明确完成计划或结束会话后乘船离开。等待确认时头顶有问号，报错时变红并加快脚步。没有新日志只表示暂时歇息，不会推算任务完成；已经上船后收到新任务，会完成航程再回来。工作台屏幕与动作节奏跟随 CPU。普通居民是场景生活，江面上的信号船对应浏览器、Agent、内存、网络与播放器。

远处增加两层城区和港口轮廓；近处楼宇有立面阴影、店招、阳台、屋顶设备和绿植。前景还保留花箱、单车、骑行者、钓鱼居民与小猫。在交互模式把鼠标移到居民或设施上，可以看到当前活动说明。

楼宇、树木、船体与路面随同一片天空受光：白天偏灰蓝，黄昏带暖色，夜里保留冷色暗面与灯光。楼宇的侧面、窗洞和细纹理让远近景的材质更协调，树冠保留体积但减少杂乱亮点。

滨水步道有石材铺装、成组树木与低矮灌木、栏杆路灯、骑行带和导览设施。树冠有背光与受光层次；宽屏增加藤架长椅和咖啡露台。居民在有遮阳篷的小店旁点单，在候船廊等候，经栈桥登船。各城的通勤渡轮保留居民登船互动，并有独立的前景航道。信号船使用远近两档图案：每三个浏览器标签增加一艘小船，最多四艘；最多两个活跃 Agent 对应工程船，等待确认时吊机停下；内存占用决定货驳的货箱数量；网络活跃度影响最多两艘快艇及其进出港速度；播放器开启时有灯光游船，灯光跟随实际频谱。船群每秒协调一次，含离港船最多十四艘，小尺寸画面按可用泊位减少船量。

## 数据来源

- 系统：每秒读取 CPU、内存和网络速率；CPU 信号减去本程序及 WebView2 子进程的占用。
- 音频：通过 WASAPI 读取系统播放输出，计算三频段和七段频谱；不启用麦克风，不保存原始音频。
- 媒体：通过 Windows 媒体会话获取播放状态、曲名、艺人和封面配色。没有支持该接口的播放器时显示等待状态。
- Agent：只读跟踪用户目录下 Codex 和 Claude Code 的 JSONL 记录；识别会话、任务列表、工具调用和可确认的测试结果。未知结果不会被标记为测试通过。
- 新版 Codex 桌面日志中的思考、回复、命令执行和文件修改会显示在左侧活动卡片，实际工具活动驱动施工楼。没有任务清单时显示活动次数，不推算任务完成百分比。
- 浏览器：通过 Windows 辅助功能接口计数 Edge、Chrome、Firefox 等浏览器的标签，不读取标题或网址。需要类别时，可按下文加载可选扩展。
- 天气：通过 HTTPS 获取 Open-Meteo 城市天气，每十分钟更新。包含温度、湿度、风速、风向、云量、降水和城市当地时间。数据来自天气模型，不是本机传感器。天气决定云层、风雨、雪与雷电；联网失败时提示原因，有三小时内缓存时暂用缓存。

控制台“本机数据”提供逐项开关。隐私模式隐藏任务和曲名，并对后续记录脱敏。导出记录默认脱敏；勾选“导出中包含任务和曲名”后才包含原文字。

天气位置有三种来源，展开“本机数据”，选择位置来源后点“应用”：

- 系统城市：读取 Windows 已授权的位置，使用随程序提供的 GeoNames 数据在本地匹配附近城市。联网查询天气前，把坐标取整到约十公里网格；不保存或发送原始精确坐标，不使用额外的 IP 定位或联网城市反查服务。附近城市名称是距离匹配，不是行政边界判定。Windows 定位不可用时显示原因，保留有效缓存，不把场景城市当作系统城市。新安装默认使用系统城市；既有配置保留原选项。
- 跟随场景：外滩为上海，曼哈顿为纽约，维港为香港。
- 固定城市：输入名称后应用。搜索默认采用首个匹配，同名时可填写更完整名称并核对左上角城市名。

Windows 定位开关位于“设置 → 隐私和安全性 → 位置”。系统城市需要允许桌面应用使用位置；程序不会自行更改系统开关。联网天气只发送已取整的位置或城市查询，不发送 Agent、系统资源或音频信息。

“画面 → 氛围”有原貌、轻量和数字氛围三档。数字氛围以细密字符、电路纹理、扫描光带、信号流和少量故障闪烁呈现本机活动。保留当前物理像素字格精细度，天气、Agent 和控制台采用统一的等宽字体、细边框和信号配色。雨滴涟漪、飘雪、雷电和雨后彩虹按天气触发。

## 天气月亮与负载气候

月亮以原有圆形点阵作为表情屏，无外圈描边。表情参考 Emoji：晴天微笑，下雨流泪，多云困倦，雪天发冷，雷暴惊讶，雾天显示朦胧表情。数据来自上方选择的天气城市，默认跟随 Windows 系统城市。天气月亮启用时替代原日月圆盘及倒影，白天也只显示这一颗；没有实况数据时使用原日夜逻辑。

控制台“气候映射”默认选择“跟随本机负载”：CPU 达到自定义阈值后依次多云、下雨、雷暴，内存超过起雾阈值且未达到雨/雷暴阈值时起雾。默认 CPU 阈值为 20%、45%、70%，内存 85%；轻负载电脑可自行调低。平滑时间默认 8 秒，最短保持 5 秒，释放时有少量滞回，避免在阈值附近频繁切换。点击“保存阈值”后随便携设置保留。也可选择城市气候直接跟随实况，月亮始终表示实况。

## 江面状态与桌面烟花

“江面字符”默认只显示两处低亮度状态：CPU / 内存和最近一个 Agent 的实际动作。有明确任务计划时显示完成步数，没有计划时显示实际工具次数。支持内容选择、浓度和普通倒影；01 模式把 CPU 与内存的百分比数值编码为八位二进制。

桌面状态下单击空白处可放烟花；单击图标、拖动框选和操作其他窗口不会触发。“本机数据 → 单击桌面空白处放烟花”可关闭。手动暂停动画时，烟花随世界一起暂停。

## 小组件位置

打开控制台，选择“画面 → 摆放小组件”，分别拖动天气、Agent 组件的标题栏。也可以聚焦标题栏后用方向键微调，Shift 加方向键每次移动十像素。松开鼠标后自动保存，点击“完成”或按 Esc 结束编辑。“恢复默认”重置两个组件的位置。

位置保存在便携目录的设置中，重启和切换场景后保留；分辨率变化时自动限制在屏幕内。桌面状态下小组件不拦截鼠标，便于正常操作桌面图标。

天气数据与字段说明：[Open-Meteo](https://open-meteo.com/en/docs)。免费天气服务适用于非商业用途。

## 操作与节能

- 交互模式 30 fps，桌面模式 12 fps，电池供电时桌面模式 6 fps。
- 主循环只按目标帧率唤醒；暂停时每秒维护一次世界和状态，隐藏时停止调度。静音音频帧降为每秒最多一次，系统音频通过 WASAPI 事件唤醒。
- 默认在前台窗口最大化或全屏时暂停绘制，继续采集和记录。可以在控制台关闭这项设置。
- 全局快捷键：Win+Alt+W 打开/收起控制台，Win+Alt+P 切换隐私模式，Win+Alt+S 切换场景。
- 如果快捷键已被其他应用占用，自动尝试 Ctrl+Alt+W/P/S。当前可用组合显示在数据源状态区域；托盘操作始终可用。
- 开机启动由托盘菜单或控制台复选框控制。移动文件夹后，关闭再开启一次，更新启动路径。

时间轴保留最近 15 分钟，事件还受 10,000 条和 6 MiB 的上限限制；超过容量时窗口可能提前缩短。音频帧不写入前端历史，回放无法精确还原实时频谱。导出包含窗口起点的检查点，默认同时清理其中的任务、曲名与日志文字，文件上限 10 MiB。原生按天日志仍独立保留十四天，并对音频降采样。

## 数据与记录

便携版在自身目录的 `data` 文件夹保存设置、WebView2 缓存、事件日志和导出文件。日志按天保存，默认保留十四天。程序目录不可写时，改用 `%LOCALAPPDATA%\AsciiCity`。

`data/runtime.json` 是本机采集接口的端口和配对令牌；请勿公开分享。程序每次启动都会更换令牌。发布 ZIP 不包含任何本机数据或令牌。

前端时间轴回放本次运行；JSONL 导出位于 `data/exports`。后台原始事件日志位于 `data/logs`，音频只保存每秒的信号摘要。

## 可选浏览器类别扩展

内置标签计数无需扩展。要让浏览器船的类型和颜色对应网页类别：

1. 在 Edge 或 Chrome 的扩展页开启开发者模式。
2. “加载解压缩的扩展”，选择此文件夹中的 `browser-extension`。
3. 打开扩展选项，从 `data/runtime.json` 填入端口和令牌。

分类只在扩展内进行；发给壁纸的内容只有标签标识与类别。扩展不会发送网址和标题。重启壁纸后需更新连接参数。

## 退出与恢复

程序不替换系统壁纸图片；退出时移除自己的窗口，原桌面继续显示。可与其他桌面背景程序共存，但同时运行的程序各自占用资源。

发生问题时，先查看 `data/host.log` 和 `data/status.json`。显示器布局改变或 Explorer 重启后，程序会尝试重新挂载。若挂载失败，可从托盘重试或退出后重启。
