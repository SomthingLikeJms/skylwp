## Windows 原生集成

本机为 Windows 11 x64（10.0.26300）、20 个逻辑处理器，WebView2 156.0.4314.58。

- 实际桌面与客户区均为 **3840×2160**，DPI 168（175%）。
- 父窗口为 Progman；上层为 SHELLDLL_DefView 图标层，下层为 WorkerW。壁纸可见且不带置顶标志。
- 交互与桌面往返、隐私、手动暂停、前台覆盖暂停通过，无页面异常、无世界重载。
- 系统、音频回环、真实 Agent JSONL 和浏览器计数事件已进入前端，拒收事件数为零。
- 本机没有活动媒体会话时正确显示“等待播放器”；未伪造曲名或播放状态。
- Stop / 托盘退出后运行接口文件被移除，原系统壁纸配置保持不变。
- 最终 ZIP 只包含可分发文件，未包含 data、历史日志或配对令牌。程序直接依赖系统 DLL 和随包 WebView2Loader.dll，不加载 Node.js 或 Rust 开发工具。

### 整组进程短时采样

0.3 版在 3840×2160、427×121 字格、沉浸效果、桌面 12 fps 下测量。统计主程序、全部后代及使用本程序数据目录的 WebView2 进程，共 7 个进程。运行采样 **15.3 秒**，暂停采样 **17.5 秒**；暂停期间采集继续。结果为此机器上的短时测量，不代表长时间运行或其他硬件。

| 状态 | 整机 CPU | 私有工作集 | 工作集合计 | 私有提交量 |
| --- | ---: | ---: | ---: | ---: |
| 运行 | 0.66% | 118.6 MiB | 249.0 MiB | 524.6 MiB |
| 暂停 | 0.34% | 112.8 MiB | 244.5 MiB | 534.7 MiB |

工作集合计会重复计算进程间共享页；私有工作集表示各进程私有的物理驻留页。GPU 利用率、电池供电和跨日稳定性尚未完成专门采样。

## 0.3 实况连接验证

- `witness.json` 记录本次实际编辑文件后，原生工具计数增加，前端接收到 Codex 的 `edit` 事件，未使用模拟 Agent 注入。
- `fixed-city.json` 记录通过实际城市搜索取得南京天气，并验证在线天气关闭和恢复。
- `warm-1.json` 与 `final.json` 记录带缓存的连续重启。宿主给事件分配顺序号，启动快照使用同一毫秒内的发布顺序；前端用快照游标过滤已经应用的事件，启动期间的新事件仍进入队列。
- 最终浏览器与原生验证均无页面异常，拒收事件为零，模式往返不重载世界。

## 0.5.0 天气月亮、状态倒影与桌面烟花

前端 36 项、原生 16 项测试通过，覆盖负载阈值、低阈值滞回、实况月亮与负载气候独立、配置校验、实际状态读数、桌面手势、物理坐标与点击事件回放。记录规则升级为 `city-v4`；旧记录使用原版本打开。

原生验证使用实际采集信号：低 CPU 阈值触发雷暴，提高阈值后恢复晴天，实况天气保持独立。通过实际进程重启验证自定义阈值保存，之后恢复测试前设置；既有小组件位置、字格、主题和系统城市选择保持一致。报告为 `native-climate-exercise.json` 与 `native-climate-verified.json`。

桌面烟花使用实际 Windows 鼠标输入验证。系统原生命中测试选择空白处，原生计数和前端记录均收到一次 `desktop.click`，拖动后计数保持不变；窗口与鼠标位置在测试后恢复。图标检查限定在 Explorer 桌面列表，以精确命中区分图标、文字和空隙，避免透明 WebView 与图标整格矩形干扰。证据为 `desktop-click-report.json`、`desktop-frontend-receipt.json` 和 `native-desktop-firework.png`。
