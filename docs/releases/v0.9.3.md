# Skylwp 0.9.3 — Windows 便携预览版

这是首个公开便携发布包。本机系统、Agent、浏览器与播放活动会驱动一座 ASCII 城市，包含外滩、曼哈顿和维港三个场景。

## 下载

- `Skylwp-0.9.3-windows-x64.zip`：Windows x64 动态壁纸。完整解压后双击 `AsciiCity.exe`，保留同目录 DLL；需要已安装的 Microsoft Edge WebView2 Runtime，无需 Node.js、Rust 或 Wallpaper Engine。当前实机验证环境为 Windows 11。
- `Skylwp-0.9.3-browser-preview.zip`：完整解压后打开 `Preview.html`。使用模拟信号，不采集本机数据，也不挂载桌面。
- `SHA256SUMS.txt`：两个 ZIP 的 SHA-256 校验值，可用 PowerShell `Get-FileHash 文件名 -Algorithm SHA256` 核对。

双击托盘图标打开控制台，Esc 返回桌面；通过托盘或 `Stop.cmd` 退出。升级前先退出旧程序，覆盖应用文件并保留原目录中的 `data` 文件夹。

## 本版内容

- 居民会买咖啡、找座位、等渡轮和登船；真实 Agent 的活动关联居民行程。
- 浏览器、Agent、内存、网络与播放器驱动不同船型、数量和动作。
- 补充远景城区、楼宇细节与滨水设施，统一楼宇、树木和船只的材质与灯光。
- 小组件可移除、恢复、拖动与调整透明度，设置会保存。
- 限制事件历史容量，实时音频帧不写入历史；减少采集轮询与空转，缓存静态图层。
- 修复 Windows 11 下壁纸覆盖桌面图标的问题。
- 补齐 MIT 许可证、第三方许可文本和源码来源说明。

## 数据与验证

本机采集项目可在控制台逐项关闭，音频使用系统播放回环，不读取麦克风；不保存原始音频。任务标题与曲名默认只保存在本地，手动导出默认脱敏。天气查询使用 Open-Meteo，联网请求只包含所选城市或取整后的粗略坐标。

63 项前端测试、TypeScript 严格检查、离线浏览器检查和 Windows release 构建通过；原生运行时修复曾通过 20 项 Rust 测试。实际采集画面、重启后的配置保留和桌面图标层级已在本机验证。发布 ZIP 不含本机数据、日志、配对令牌或开发工具链。

## 已知限制

- 仍是预览版，尚未覆盖其他 Windows 版本、不同硬件及长时间稳定性。
- 4K 对应网格的 CPU 合成均值约 4.5–4.8 ms，仍高于 4 ms 目标；此值不包含 GPU 与原生宿主开销。
- 播放器信息取决于 Windows 媒体会话支持；没有可用会话时显示等待状态。
- 可执行文件尚未进行代码签名。

项目代码采用 MIT；第三方组件、数据和天气服务各自的条款见包内许可说明。
